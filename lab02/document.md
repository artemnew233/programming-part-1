## Features

### Table of contents (TOC)

- Use command **Markdown All in One: Create Table of Contents**.
- TOC auto-updates on save by default (`toc.updateOnSave`).
- To hide a section from TOC add `<!-- no toc -->` above it.

### List editing

- Press **Enter** inside a list item to continue the list.
- Press **Tab** to indent / `Shift+Tab` to unindent.
- Ordered lists can be auto-fixed (option: `list.fixOrderedListMarker`).

#### Example

```
1. First
2. Second
   - Sub
```

### Print Markdown to HTML

- Command: **Print current document to HTML**.
- Set title using `<!-- title: My Title -->` on the first line.
- `.md` links are converted to `.html` in export.

### GitHub Flavored Markdown

- Task list:

  - [ ] todo item

- Strikethrough: ~~text~~

### Math

- Inline: `$E = mc^2$`.
- Display: `$$\int_0^1 x^2 dx$$`

### Others (small useful bits)

- Paste a link on selected text to wrap it as `[text](url)`.
- `Close Preview` keybinding can be added to mirror `Open Preview`.
